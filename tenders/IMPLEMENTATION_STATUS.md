# Состояние программы Sultan Trade — 18 ноября 2026

## Реализовано в работающем приложении

- Существующий магазин сохранён; /tenders закрыт серверной авторизацией сотрудников.
- Supabase: лоты, рабочие статусы, избранное, настройки, синхронизации и история;
  RLS и запрет клиентского доступа к внутренним таблицам.
- Импорт официальной JSON-выгрузки с предварительной проверкой, защитой от дублей,
  журналом ошибок; явно обозначенный демо-адаптер.
- Каталог, фильтры, сортировка, карточки, первоисточники, статусы и история.
- PDF/DOCX/XLSX/TXT: извлечение текста, требования с точными цитатами, ручная
  проверка, версии документа и перенос требований в сравнение.
- Серверный AI-адаптер со строгим форматом и проверкой цитат, согласие на отправку;
  без ключа используется явно предварительный разбор, не имитация AI.
- Каталог Stockera/Al-Style, ручные предложения КЗ/Китая, модель/параметры,
  валюта/дата/курс, доставка, таможня и импортный НДС; проверка давности цены.
- Финансовый калькулятор с отдельными НДС, КПН, резервом, финансированием,
  чистой прибылью и минимальной ценой; ставки и периоды задаются явно.
- Прозрачный базовый и расширенный рейтинг с весами и полнотой данных.
- Excel: одна закупка или весь отфильтрованный список, ровно восемь колонок;
  личные сохранённые расчёты, без подмены неизвестных сумм нулями. JSON-отчёт.
- Контроль подготовки заявки: факты, проблемы, неизвестное и ручное решение.
- Фоновый планировщик подключённых API, отсутствие параллельных синхронизаций,
  состояние и журнал. Уведомления исключены по просьбе владельца.

## Подготовка 1С:Бухгалтерия для Казахстана

Добавлен защищённый пакет анализа тендеров в собственном JSON-формате, описание
схемы и модуль структурной проверки BSL. Связь с действующей 1С, создание
справочников/документов и проведение не включены. Код BSL требует проверки
на конкретном релизе. Порядок: [onec/README.md](onec/README.md).

## Внешние ограничения — не замаскированы фиктивными интеграциями

1. Официальный API госзакупок: нужны разрешённый доступ/токен и подтверждённый
   формат оператора. 18.11.2026 официальные страницы goszakup.gov.kz и
   ows.goszakup.gov.kz вернули HTTP 503 из рабочего окружения. Текущий адаптер
   не выполняет неподтверждённые запросы; одного токена недостаточно без формата.
   Рабочий путь получения данных сейчас — импорт официальной JSON-выгрузки.
2. OpenAI: серверные OPENAI_API_KEY и OPENAI_MODEL. Не создаём платный аккаунт
   и не включаем оплату автоматически; сохранённые документы доступны без AI.
3. 1688: ручное предложение с источником. Автопоиск требует разрешённого API
   поставщика и его учётных данных; цены не выдумываются.
4. Pinduoduo/Самрук-Казына: автоматическая интеграция выключена до подтверждения
   разрешённого способа доступа. Ручной ввод предложений работает.

Сохранённые веб-цены/наличие не являются действующим КП или резервом товара.
Контрольный список не заменяет проверку лицензий, договора и решение руководителя.
Сканы без текстового слоя требуют распознавания/ручной подготовки текста, а не
выдуманного содержания. Статус «API подключён» не показывается без подключения.

Проверки запуска: npm ci; npm run test:tenders. Frontend: npm ci; npm run build.
Миграции применяются отдельно; автоматический запуск сервера не меняет схему БД.
