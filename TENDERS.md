# Раздел «Тендеры» (фронтенд)

Страница `/tenders` (`src/pages/tenders/`). Работает только вместе с бэкендом из ветки `feature/tenders-backend` (см. `tenders/README.md` там).

- Ссылка «Тендеры» в шапке появляется только у аккаунтов, которым бэкенд открыл раздел (`TENDERS_ALLOWED_EMAILS` на Railway). Остальным покупателям раздел и ссылка не видны, API отвечает 403.
- Вкладки: Обзор (счётчики, ближайшие сроки, ошибки синхронизации), Лоты (поиск, фильтры, сортировка, избранное, рабочие статусы, карточка с разбором рейтинга), Источники (статус подключения, дата последней успешной синхронизации, загрузка файла лотов, демо-данные, веса рейтинга).
- Языки: русский и казахский (переключатель RU/KZ, выбор запоминается). Казахский перевод интерфейса сделан нами и требует вычитки носителем.
- Страница загружается отдельным чанком, на скорость магазина не влияет.
- Секретов и ключей в браузере нет: запросы идут с токеном вошедшего пользователя.

Проверки: `npm run build`, `node --test tests/*.test.mjs`.
