# Stockera / Sultan Trade AI

Существующий интернет-магазин ТОО «Султан Trade LD»: React + Vite, Express, Supabase, серверная интеграция al-style.kz.

Добавлен MVP Tender Intelligence: `/tenders` — каталог закупок, фильтры, избранное, рабочие статусы, базовая оценка и журнал синхронизации.

## Разработка магазина

Node.js 22.12+:

```bash
npm install
npm --prefix backend install
npm run dev
```

Frontend: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (публичный anon ключ), `VITE_BACKEND_URL` (production/staging). Локальный Vite proxy магазина по умолчанию направлен на существующий Railway backend; для тендерного demo см. отдельную инструкцию выше.

Backend: `ALSTYLE_ACCESS_TOKEN`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ALLOWED_ORIGINS`; остальные настройки в backend/README.md. Секреты поставщиков и AI нельзя хранить в `VITE_*` или коммитить в Git.

```bash
npm run build
npm --prefix backend test
```

Демо-закупки вымышлены. Официальные источники отключены до подтверждения доступа. Миграция новых таблиц подготовлена для отдельной dev/staging базы; production не изменялся. Развёртывание требует подтверждения владельца.

### Каталог в финансовом расчёте тендера

Упрощённый подбор использует защищённый `/api/tenders/suppliers/search`, сохраняет
валюту и дату цены источника. Неизвестная дата/валюта или служебная цена ≤1 блокирует
добавление. Для валютного предложения нужно вручную указать курс и дату курса;
пустое значение не превращается в нулевую стоимость. Цена остаётся справочной.
Перенос оборудования сбрасывает подтверждение расходов и не предполагает право
на зачёт НДС. Сохранённые ранее предложения автоматически не исправляются.

Проверка преобразования: `node --test src/pages/tenders/catalogOffer.test.js`.

### Видимый рабочий кабинет сотрудников

После входа сотрудника: `/tenders`. Вверху есть отдельное меню рабочих разделов.
Прямые переходы: `/tenders#financial-summary`, `/tenders#whatsapp-preparation`,
`/tenders#tender-list-report`, `/tenders#tender-sources`.
Финансовая сводка открыта по умолчанию; переход по кнопке раскрывает нужный блок.
WhatsApp показывает только подготовленную архитектуру. Номер и ключи не настроены,
сообщения и уведомления не отправляются. Модуль недоступен обычным покупателям.


Рабочая доска команды: `/tenders#tender-work-board`. Показаны все отфильтрованные
страницы (до 200), статусы переключаются через доступные на мобильном экране
списки. Общая заметка в карточке защищена от незаметной перезаписи чужой правкой;
при конфликте локальный текст остаётся и предлагается явная сверка версий.

В production сохранение общих заметок временно выключено: применение новой
SQL-функции отклонено автоматической проверкой до отдельного разрешения владельца.
Доска, смена статусов и просмотр заметок работают независимо.

### Финансовые сценарии
В карточке → «Себестоимость и прибыль» → «Запас прочности» сравните исходные поля с выбранным снижением цены и ростом всех расходов. Это допущения: сценарии не сохраняются, не меняют обычный расчёт и отчёт. Изменение полей скрывает устаревшие результаты. Цена безубыточности отделена от цены с целевой прибылью.
